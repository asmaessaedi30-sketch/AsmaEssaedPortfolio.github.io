    Data Cleaning in SQL

    This project cleaned a real-world dataset of Nashville property sales by resolving inconsistencies that make analysis difficult—such as mixed date formats, missing addresses, combined fields, and irregular values. The process included standardizing dates, using SQL self-joins to logically fill missing addresses based on Parcel ID, and splitting address fields into separate columns for street, city, and state. I also normalized categorical values and removed duplicate entries. The result is a clean, reliable dataset ready for analysis—whether for market trends, geographic insights, or property valuation—free from the noise that often hides useful stories in raw data.
